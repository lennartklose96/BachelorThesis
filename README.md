#### File format for ILP instances
The format for the generated instances is:

\# OF INSTANCES <br>
(start repeat) <br>
n r h <br>
t <br>
c <br>
RHS <br>
matrix <br>
blank line <br>
(end repeat) <br>

s has been omitted for now, as it's set to s = 1
