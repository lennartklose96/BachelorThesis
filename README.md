# Implementation of Combinatorial n-fold Algorithms	
This repository containing the code for my bachelors thesis.

The Java Code for the implemented Algorithms can be found in:
Code/Java/ILPAlgo/src

For the specific implementations of the algorithms, the relevant files are named:
- JKPT25Alg.java
- JRAlg.java
- GKPT25Alg.java
- Rohwedder25Alg.java

The other implemented classes hold some specific Objects useful for the processing, such as reading the Instances.
The GurobiTest class was mainly used to (help) verify correctness of the algorithms, and compare their results with each other.
